TruthLens AI

AI-Powered Video Verification & Deepfake Detection

TruthLens is an AI-based video verification system designed to identify potentially manipulated or AI-generated video content. It analyzes video frames using computer vision and deep learning techniques to generate a probabilistic credibility assessment.

🚀 Overview

TruthLens processes uploaded videos, extracts relevant frames, analyzes them using an AI detection pipeline, and aggregates frame-level predictions to estimate the likelihood of manipulation.

🎯 Objectives

* Detect potentially AI-generated and manipulated videos.
* Apply deep learning and computer vision to digital media verification.
* Build an automated video-analysis pipeline.
* Provide probabilistic results rather than a simple binary decision.

🔬 How It Works

1. User uploads a video.
2. OpenCV extracts frames from the video.
3. Relevant visual/face regions are processed.
4. The AI model generates predictions for analyzed frames.
5. Predictions are aggregated to produce an overall credibility score.
6. Results are presented through the web interface.

⚠️ Limitations

Detection is probabilistic and cannot guarantee absolute authenticity. Performance can vary depending on video quality, compression, resolution, face visibility, and manipulation technique.
